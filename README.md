# 所有人保持Q弹 · Q-BOUNCE

> Q弹小人生成器 / Bounce Animation Exporter
> 纯前端、零依赖、打开即用 —— 图片全程在浏览器里处理，不上传服务器。

把一张带透明底的小人图丢进来，它就会随着 130 BPM 的节拍压扁、回弹、摇摆，然后导出成 GIF。支持多个主体一起弹、3D 旋转、竖屏/方图/横屏多种比例导出。

## 快速开始

无需构建、无需安装依赖，起个静态服务器即可：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

也可以直接双击 `index.html` 以 `file://` 方式打开，两种方式都能跑。

点 **载入示例** 立即看效果，再点 **导出 GIF** 就能拿到成品。

## 功能

| 分区 | 说明 |
| --- | --- |
| **01 预览** | 实时动画预览，显示当前导出比例的裁切范围 |
| **02 图像** | 背景图 + 多主体上传；支持拖到窗口、`Ctrl+V` 粘贴；载示例 / 清空 / 删除单个主体 |
| **03 摇法** | 速度（1.0×）、幅度（50%），节奏固定 130 BPM |
| **04 大小** | 主体与背景独立缩放 |
| **05 立体** | 3D 绕竖轴旋转、转速、厚度（厚度取自图片边缘的杂色，0 也照转） |
| **06 导出** | 比例 / 尺寸 / 帧率 / 底色 / 颜色抖动 / 地面投影 |

### 导出选项

- **比例**：`1:1`（默认）、`16:9`、`16:10`、`4:3`、`3:4`、`9:16`、自定义
- **尺寸**：320 / 480 / 640（长边像素）
- **帧率**：12 / 15 / 20 / 30 FPS
- **底色**：跟随背景图 / 纯色 / 透明
- **优化**：颜色抖动（渐变更顺）、地面投影（按主体轮廓）

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 移动选中主体 | 方向键 `↑ ↓ ← →`（按住 `Shift` ×10） |
| 删除选中主体 | `Delete` / `Backspace`，或点「删除」按钮 |
| 缩放主体 | 画布上滚动滚轮 |
| 移动画布上的主体 | 直接拖动 |
| 粘贴图片 | `Ctrl+V` |
| 导入图片 | 拖文件到窗口任意位置 |


## 技术说明

- **无框架、无构建**：原生 HTML / CSS / JavaScript，改完刷新即可看到效果。
- **零依赖导出**：`gif.js` 是手写的 GIF89a 编码器，包含中位切分量化与 LZW 压缩，不引入任何第三方库。
- **纯客户端**：图片与音乐只在你的浏览器里读取，不经过任何服务器、没有网络请求上传。
- **导出对齐**：旋转动画会在导出时对齐为整数圈，循环播放处不跳变。
